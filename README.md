# Campus Resource Reservation System

A C++ Campus Reservation System developed as a group project.

## Team Members

-Luke Wilhelm
-Jose Verdin
-Alexander Putnam

## Project Description

This system manages campus resources, reservations, waiting lists, and cancellation history.

## Features

-Resource management
-Reservation management
-Linked list for active reservations
-Queue-based waiting lists
-Stack0based cancellation history
-Resource searching and sorting
-Reservation reports
